SteamVR Gesture Exit is a SteamVR add-on that lets you wave goodbye, strike a pose, and exit VRChat and other supported VR games in style.

## What it does

Leaving a social VR game through menus can feel awkward. Other players see you open panels, click around, or walk away before you disappear.

SteamVR Gesture Exit turns that awkward moment into your own final scene. Wave goodbye, strike a signature pose, or pull off a full body exit move while the countdown runs. When it reaches zero, the game closes and you return to SteamVR.

To everyone around you, it looks like you disappeared right on cue. It is the VR version of a hero's exit, with the timing and style entirely up to you.

## Quick start

Once installed, SteamVR Gesture Exit is ready to use whenever you start SteamVR.

1. Open it from the SteamVR Dashboard whenever you want to change the settings.

2. Enter a supported VR game and wave goodbye to bring up the exit control.

The interface supports English and Chinese.

## Supported games

The add-on is designed mainly for VRChat, where a good exit can be part of the moment. It also works with other reviewed social and multiplayer VR titles.

See the current [supported VR games](config/supported_vr_games.json). If your favorite VR game is missing, feel free to open a PR and add it to the list.
